# nickypro/homebrew-tap

Homebrew formulae for my tools.

```sh
brew install nickypro/tap/pdftk-rs
```

| Formula | What it is |
|---|---|
| [`pdftk-rs`](https://github.com/nickypro/pdftk-rs) | pdftk without the Java: a Rust port of the PDF toolkit as one small static binary |

Formulae install the prebuilt binaries from each project's GitHub release, pinned by SHA-256.
